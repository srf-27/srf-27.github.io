## Agent 是什么？
### 最初含义：Agent = 会“主动”做事的主体

“Agent”这个词来自拉丁语 _agere_，意思是「去做、去行动」。

所以最初含义非常简单：**Agent = 能感知世界、形成意图、并主动行动的主体**。

### 核心出现：Loop

最早的**智能体模型**，它的思维路径是一个闭环：

```text
感知（Perceive）
→ 推理（Reason）
→ 行动（Act）
→ 获得反馈（Observe）
→ 调整策略（Loop）
```

这一框架之核心，就在于**能闭环行动（Loop）**，它可以根据获得的反馈去进行调整。

### LLM 时代的 Agent

大模型时代，机器具备了理解自然语言、推理问题、规划行动的能力。那么很自然的，研究者就想到，如果LLM可以根据行动后获得的反馈去决定下一步要做什么，是不是就能实现自动化？

于是，LLM 时代下的 Agent 架构诞生了：

 单 Agent：
* ReAct (Reason + Act)，Loop = 推理 + 行动，直到目标达成结束
* Plan-and-Execute，Loop = 规划 + 执行，某一步失败重新规划
* Reflection，Loop = 行动 + 反思 + 调整，自我反思与修正
* AutoGPT
* LangChain
* ……
multi-Agent：
大体上可以分成主从模式，对等模式，流水线模式

那么 Agent 现在到底是什么：
model + planning + memory + tools + 一个达到goal才终结的loop

或者来看一个更轻框架：
我们把一个操作视为一个节点 node，那么一个工作流 workflow = node + … + node，一个chatbot = workflow + loop（早期的llm就是差不多这个流程，一问一答的loop），

**agent = chatbot + tools（可以自主调用特定工具来处理复杂任务）= workflow + loop + tools +（memory）**
