简单用docker配了一下headtail来连云服务器，这里随便塞一些指令吧
#### 服务端注册节点

#### 使用 PreAuth Key
```
# 创建用户
docker exec headscale headscale users create <USER_NAME>

# 查看用户ID
docker exec headscale headscale users list

# 生成预认证密钥
docker exec headscale headscale preauthkeys create --user <USER_ID>
```
#### 客户端加入指令
```
tailscale up --login-server <YOUR_HEADSCALE_URL> --authkey <YOUR_AUTH_KEY>
```
用自己的电脑和虚拟机测试，都可以连上云服务器，打出的直连隧道也可以用来局域网连接，mc原版联机速度倒是够用，不知道上限是多少。

但是用异校的同学电脑测试，发现连上去马上就掉了，且连接用时始终很长，用tailscale netcheck查看，发现他的网络环境`MappingVariesByDestIP`为 `true`，表明是严格的对称型 NAT，这个网络环境大概是没招了。
docker不开代理的拉取镜像速度也是实在很慢，现改用[Docker Registry Mirror - hub.bravexist.cn](https://hub.bravexist.cn/)，基本能用了。
